# /cfe-diff — Анализ расширения

Что изменено в расширении: по каждому заимствованному объекту — перехватчики и собственные методы модулей, собственные подобъекты, правки форм; собственные объекты — составом.

## Параметры

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `ExtensionPath` | Расширение; несколько — через запятую; каталог, в подкаталогах которого лежат расширения (обязат.) | — |
| `Name` | Детали только по этим объектам: `Тип.Имя`, через запятую | — |
| `Expand` | Заимствованные без правок: `Тип.Имя` — показать объект, `*` — перечислить все в итоге | — |
| `Limit` / `Offset` | Пагинация тела отчёта | `150` / `0` |
| `OutFile` | Записать отчёт в файл | — |

## Команда

```powershell
python ".roo/skills/cfe-diff/scripts/cfe-diff.py" -ExtensionPath src\cfe\extname
```

## Вывод

Итог — в конце. Если отчёт большой, детали опускаются: запроси их через `-Name` (несколько объектов через запятую).

Правки заимствованной формы показаны относительно исходной (`BaseForm`): `+` добавлено, `~` изменено (`было→стало`), `>` перемещено. Форму целиком, с наложенными правками, показывает `/form-info`.

## Примеры

```powershell
# Что изменено в расширении
... -ExtensionPath src\cfe\extname

# Детали по двум объектам
... -ExtensionPath src\cfe\extname -Name Document.ЗаказКлиента,CommonModule.ОбщегоНазначения
```

Перенесены ли правки в основную конфигурацию — `/cfe-transfer`.
