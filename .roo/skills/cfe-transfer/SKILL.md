# /cfe-transfer — Перенос правок расширения в конфигурацию

Укажи пути к XML-выгрузкам. `-ExtensionPath` — расширение, `-ConfigPath` — основная конфигурация. Для сверки используй `check`, для записи в выгрузку — `transfer`.

## check

```powershell
python ".roo/skills/cfe-transfer/scripts/cfe-transfer.py" -ExtensionPath src/cfe/extname -ConfigPath src/cf -Mode check
```

- `check` — режим по умолчанию. Для сверки нескольких расширений передай их пути через запятую или укажи каталог расширений.
- Если нужен конкретный объект или подробности по остатку, укажи `-Name "Document.ЗаказКлиента,Catalog.Номенклатура"`. Используй имена из расширения. `-Name` отбирает объект целиком. Для переноса одной правки сначала убедись через `check`, что она единственная в остатке по этому объекту.
- Чтобы раскрыть свёрнутые строки, передай в `-Expand` имя объекта, путь раздела из отчёта или `"*"`. Для обрезанного отчёта `-Limit` и `-Offset` задают размер и смещение страницы (по умолчанию 150 и 0). В режиме `check` параметр `-OutFile` сохраняет текущую страницу.
- Смотри итог и остаток. Если хотя бы одно имя из `-Name` не найдено, отчёт перечислит пропуски и скрипт вернёт код `1`. Если совпадение помечено `heuristic`, проверь поведение по исходному и перенесённому коду, когда нужна уверенная сверка.
- Собственные пользовательские роли входят в проверку и перенос. Чтобы включить собственные роли из `DefaultRoles` расширения, передай `-IncludeDefaultRoles` в обоих режимах. Назначение ролей проверяется отдельно.

## transfer

```powershell
python ".roo/skills/cfe-transfer/scripts/cfe-transfer.py" -ExtensionPath src/cfe/extname -ConfigPath src/cf -Mode transfer -OutFile "<путь-к-отчёту>"
```

1. Сверь исходное состояние через `check`. Переноси по одному расширению за запуск. Для выборочного переноса используй тот же `-Name`. Если настройка проекта требует метку для комментариев, передай `-Tag <метка>`, например номер задачи. При отсутствии обязательной метки скрипт остановится до записи. Возьми её из задачи или уточни у пользователя.
2. Сразу укажи в `-OutFile` путь вне каталога выгрузки. Полный отчёт относится к этому запуску, а новый вызов заново запускает перенос. Код `1` допускает частичную запись, в том числе если найдена только часть имён из `-Name`. Сверься с `transferred now` и списком изменённых файлов.
3. Разбери причины `MANUAL` и `CONFLICT` по отчёту. Для отклонённой формы начни с общей причины. Если исправление требует выбрать итоговое поведение, вынеси этот выбор пользователю.
4. Для `WAITING` проверь, какой правки или объекта ещё нет в основной конфигурации. Если условие связано с отбором, сверь нужные объекты с `-Name`. Взаимозависимые объекты могут потребовать одного запуска со всеми участниками. Повтори перенос после устранения причины.
5. Выбери проверку по изменённым файлам. Если записан только BSL-модуль, начни с проверки его кода. Сверяй замечания с исходным состоянием. Если отчёт сообщил об отсутствующем валидаторе, выполни указанную проверку отдельно. При `WARNING` о строковом литерале проверь его назначение и меняй только подтверждённые ссылки. Целевое имя бери из отчёта или выгрузки. В конце повтори `check` с тем же отбором.

**Если в расширении есть изменения структуры хранения данных, согласуй с пользователем, какие данные и как перенести до отключения или удаления расширения.** Для согласования используй список из предупреждения `Stored data is NOT migrated`.

## Заимствованные объекты

- У справочников, ПВХ, планов счетов и ПВР можно перенести предопределённые элементы, добавленные в расширении. Если элемент добавлен в заимствованную группу, она должна существовать в основной конфигурации под той же цепочкой имён. При повторной сверке перенесённый элемент ищется по исходному GUID.
- Для существующих элементов перенос значения свойства опирается на явный режим `Extended`, а расширение типа — на `ExtendValue`. `Notify` означает предупреждение платформы. Расхождение со снимком заимствования само по себе не подтверждает переопределение.

## Временные правки

Чтобы исключить правку из остатка сверки и переноса, укажи `// Временно: <причина>` или `// Не переносить: <причина>` над методом либо на строке `#Вставка` / `#Удаление`. Для элементов формы укажи в начале модуля формы `// Не переносить элементы формы: <имена через запятую> — <причина>`. Если правка уже есть в конфигурации, отметка о временности появится рядом с ней в отчёте.

## Настройки и связанные навыки

- Настройки `devPrefix` и `cfeTransfer` в `.v8-project.json` управляют целевыми именами, обрамлением, удалением и областями. Формат описан в `/db-list`.
- Чтобы посмотреть состав изменений самого расширения, используй `/cfe-diff`.
- Чтобы актуализировать перехватчик под новую конфигурацию-источник, используй `/cfe-patch-method`. Для одного метода укажи и `-ModulePath`, и `-MethodName`.
