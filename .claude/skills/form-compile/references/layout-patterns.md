# Раскладка форм в стиле типовых

Архетипы, имена групп и элементов, ширины полей — для формы, раскладка которой не задана в задаче (ЕРП, УТ, Бухгалтерия). Форма, сгенерированная `-FromObject` / `-EmitDsl`, уже разложена так.

Обработчики событий добавляйте только под поведение из задачи: для каждого события в модуле появится процедура, которую нужно наполнить.

---

## Архетипы форм

Командная панель формы (`autoCmdBar`) — не часть раскладки: платформа выводит её над формой. У диалога она внизу (`commandBarLocation: Bottom`), у формы без команд — `None`.

### Форма документа (ЕРП, УТ)

```
├─ ГруппаСтатус: Статус (если есть)
├─ ГруппаСтраницы (pages)
│  ├─ СтраницаОсновное
│  │  ├─ ГруппаШапка (horizontal)
│  │  │  ├─ ГруппаШапкаЛево: ГруппаНомерДата (Номер + Дата «от»), Контрагент / Партнер, Подразделение
│  │  │  └─ ГруппаШапкаПраво: Организация, Склад, Договор, ХозяйственнаяОперация
│  │  └─ ГруппаКомментарийОтветственный (horizontal): Комментарий, Ответственный
│  ├─ Страница<ТЧ>: таблица Объект.<ТЧ> — по странице на табличную часть
│  └─ ГруппаДополнительно: Автор (только чтение), подписанты | Валюта, ВидЦены;
│     ГруппаДополнительныеРеквизиты (БСП)
└─ ГруппаПодвал (horizontal, если нужны итоги): состояние | ГруппаИтого
```

Второстепенное — на «Дополнительно». Без табличных частей — без страниц: шапка, комментарий, доп. реквизиты.

**Вариант Бухгалтерии** — шапка над страницами:

```
├─ ГруппаШапка (horizontal)
│  ├─ ГруппаШапкаЛевая: ГруппаНомерДата, ВидОперации, Контрагент, Договор
│  └─ ГруппаШапкаПравая: Организация, Подразделение, Склад
├─ ГруппаСтраницы (pages): по странице на табличную часть
└─ ГруппаПодвал (vertical)
   ├─ строка итогов (horizontal): … | ГруппаИтоги
   └─ ГруппаКомментарийОтветственный (horizontal): Комментарий, Ответственный
```

**Итоги** — реквизиты формы, их пересчитывает модуль формы при изменении строк: переносите вместе с расчётом из соседнего документа (`/form-info -Handlers`). Без кода — подвал таблицы: у таблицы `footer: true`, у колонки `footerDataPath: "Объект.<ТЧ>.Total<Колонка>"`.

**Свойства:** `autoTime: CurrentOrLast`, `usePostingMode: Auto`, `repostOnWrite: true`; заголовок не задавать — платформа выводит представление документа.

### Форма списка

```
├─ ГруппаПользовательскихНастроек (group, без заголовка и рамки) — у таблицы userSettingsGroup
└─ Список (table, DynamicList)
   ├─ колонки — labelField (данные только для чтения)
   │  документ: Номер, Дата, Организация, Контрагент, СуммаДокумента, Валюта, Ответственный, Комментарий (~7)
   │  справочник: Наименование, Код, Владелец + 1–2 ключевых реквизита (~3)
   └─ Ссылка — скрытая колонка (userVisible: false)
```

**Отборы:** в группе пользовательских настроек платформа сама выводит быстрые отборы, без кода в модуле. Свой отбор, которого нет в настройках, — поле `Отбор<Поле>` на реквизите формы рядом с группой, отбор ставится в `OnChange`; значение сохраняет `autoSaveDataInSettings: Use`.

### Форма элемента справочника

```
├─ Владелец (только чтение, у подчинённого)
├─ ГруппаНаименованиеКод (horizontal): Наименование, Код
├─ Родитель (у иерархического)
├─ реквизиты — по одному, сверху вниз
├─ табличные части — таблицами
├─ Комментарий
└─ ГруппаДополнительныеРеквизиты (БСП)
```

Много реквизитов — страницы или две колонки, как в шапке документа. **Свойства:** `windowOpeningMode: LockOwnerWindow` — открывается окном поверх списка.

### Форма обработки

```
├─ ГруппаПараметры (vertical): Организация, Период, режимы работы
├─ информационные надписи (label, hyperlink)
└─ рабочая область: таблица данных или страницы
```

Командная панель сверху: главное действие (`defaultButton: true`), «Закрыть» последней. Команды строк таблицы («Отметить все», «Снять отметки», «Заполнить») — в панели таблицы.

### Диалог

```
└─ поля ввода или текст вопроса
```

Командная панель внизу (`commandBarLocation: Bottom`): «ОК» (`defaultButton: true`), «Отмена». **Свойства:** `windowOpeningMode: LockOwnerWindow`.

### Мастер

```
└─ СтраницыМастера (pages, pagesRepresentation: None)
   ├─ Шаг1: описание и параметры
   ├─ Шаг2: основная работа
   └─ Шаг3: результат
```

Командная панель: «Назад», «Далее» (`defaultButton: true`), «Готово», «Закрыть»; страницы переключает код. **Свойства:** `windowOpeningMode: LockOwnerWindow`.

## Конвенции именования

### Группы

| Назначение | Имя | Тип |
|-----------|-----|-----|
| Шапка | `ГруппаШапка` | horizontal |
| Колонки шапки | `ГруппаШапкаЛево` / `ГруппаШапкаПраво` (Бухгалтерия — `ГруппаШапкаЛевая` / `ГруппаШапкаПравая`) | vertical |
| Номер+Дата | `ГруппаНомерДата` | horizontal |
| Наименование+Код | `ГруппаНаименованиеКод` | horizontal |
| Комментарий+Ответственный | `ГруппаКомментарийОтветственный` | horizontal |
| Подвал | `ГруппаПодвал` | horizontal (Бухгалтерия — vertical) |
| Итоги | `ГруппаИтого` (Бухгалтерия — `ГруппаИтоги`) | horizontal |
| Командная панель формы | `ФормаКоманднаяПанель` | autoCmdBar |
| Страницы | `ГруппаСтраницы` | pages |
| Страница | `СтраницаОсновное`, `Страница<ТЧ>`; «Дополнительно» — `ГруппаДополнительно` | page |
| Доп. реквизиты БСП | `ГруппаДополнительныеРеквизиты` | vertical |
| Отборы списка | `ГруппаПользовательскихНастроек` | group, representation none |
| Предупреждение | `ГруппаПредупреждение` | horizontal, visible: false |

### Элементы

| Назначение | Имя |
|-----------|-----|
| Поле в таблице | `<Таблица><Поле>` |
| Итог | `Итоги<Поле>` |
| Надпись-ссылка | `<Поле>Надпись` |
| Свой отбор списка | `Отбор<Поле>` |
| Кнопка команды | `<Команда>Кнопка` |
| Кнопка в панели таблицы | `<Таблица><Команда>`: `ТоварыПодбор`, `ТоварыОтметитьВсе`; подменю — `<Таблица>ГруппаЗаполнить` |
| Подменю | `Подменю<Действие>` |

### Обработчики событий

Имя = имя элемента + событие по-русски: `ОрганизацияПриИзменении`, `КонтрагентНачалоВыбора`, `ЦеныИВалютаНажатие`, `ТоварыПриОкончанииРедактирования`, `ТоварыПриНачалеРедактирования`. Обработчики формы: `ПриСозданииНаСервере`, `ПриОткрытии`, `ПередЗакрытием`, `ОбработкаОповещения`.

## Принципы компоновки

1. **Кнопки действий формы — в командной панели формы** (`autoCmdBar`), не отдельной группой на форме. Главная кнопка — `defaultButton: true`, «Закрыть» — последней.
2. **Команды строк таблицы — в командной панели таблицы** (`commandBar` у таблицы): «Отметить все» / «Снять отметки», «Заполнить», «Подбор» — рядом со стандартными командами, которые платформа выводит сама. Не в панели формы и не отдельными кнопками на форме.
3. **Отборы — над списком.** Группа пользовательских настроек; свои поля `Отбор<Поле>` — рядом с ней.
4. **Скрытые элементы для состояний.** Баннеры, предупреждения — `visible: false`, их показывает код.
5. **Надписи-ссылки вместо кнопок для подформ** (цены и валюта, учётная политика): `labelField` с `hyperlink: true` и событием `Click`.
6. **Служебное не выводить.** Реквизиты `Удалить*`, ключи и идентификаторы строк, части адреса (`…ЗначенияПолей`), табличные части БСП (`ДополнительныеРеквизиты`, `КонтактнаяИнформация`) на форму не кладут.

### Ширины полей

Поля шапки одной ширины, а не растянутые на всю форму:

| Поле | Свойства |
|------|----------|
| Ссылка, перечисление, составной тип | `autoMaxWidth: false, maxWidth: 28` |
| `Номер` | `width: 10, horizontalStretch: false` |
| `Дата` | `width: 14, horizontalStretch: false` |
| `Комментарий` | `autoMaxWidth: false, multiLine: true, titleLocation: left, verticalStretch: false`; в строке с другими полями — ещё `height: 1` |
| Строка длиннее 25 | `autoMaxWidth: false` |

Колонки табличной части:

| Колонка | Свойства |
|---------|----------|
| Номер строки | `width: 3, horizontalStretch: false` |
| `Номенклатура`, `Характеристика` | `width: 16` |
| `Упаковка` | `width: 10` |
| `Количество`, `КоличествоУпаковок` | `width: 8, horizontalStretch: false` |
| `Цена`, `Сумма`, `СуммаНДС` | `width: 9` |
| `СтавкаНДС` | `width: 9, horizontalStretch: false` |

Если есть `КоличествоУпаковок`, колонку `Количество` не выводят, а `Упаковку` ставят сразу после `КоличествоУпаковок`.

## Приёмы

| Приём | Когда | Как (ключи DSL) |
|-------|-------|------------------------------|
| Сворачиваемая группа | необязательные секции: подписи, прочее | группа с `behavior: collapsible`, свёрнутая — `collapsed: true` (`groups-pages.md`) |
| Баннер-предупреждение | сообщение о состоянии документа | горизонтальная группа `visible: false`: `picture` + `label` с `maxWidth` |
| Подменю | связанные команды (печать, отправка) — одной кнопкой | `popup` в `autoCmdBar` |
| Без командной панели | форма со своими кнопками, встроенный выбор | `commandBarLocation: None` |
| Надпись-ссылка | открыть подформу из шапки | `labelField` с `hyperlink: true`, событие `Click` |
