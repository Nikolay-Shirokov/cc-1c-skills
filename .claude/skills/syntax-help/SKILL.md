# /syntax-help — Синтакс-помощник и справка платформы

Читает справку прямо из файлов платформы (книги `*_ru.hbk` в каталоге `bin`: синтакс-помощник `shlang`, `shcntx`, `shquery` и остальная справка) — 1С запускать не нужно. Два шага: найти страницу по заголовку, затем вывести её текстом.

## Команда

```powershell
# 1. Найти страницу
powershell.exe -NoProfile -File "${CLAUDE_SKILL_DIR}/scripts/syntax-help.ps1" -Search "<слова заголовка>"

# 2. Прочитать страницу из результата поиска
powershell.exe -NoProfile -File "${CLAUDE_SKILL_DIR}/scripts/syntax-help.ps1" -Page "<книга:путь>"
```

## Параметры

| Параметр | Обязательный | Описание |
|----------|:------------:|----------|
| Search   | одно из двух | Слова заголовка страницы; регистр не важен, порядок слов не важен |
| Page     | одно из двух | Страница в виде `книга:путь` — первая колонка результата поиска |
| InText   | нет | Искать слова и в тексте страниц. Читает все страницы выбранных книг: на `shcntx` около 30 секунд на PowerShell и 5 на Python, поэтому сужай `-Book` |
| Book     | нет | Книги через запятую. По умолчанию — все книги каталога; нечитаемую поиск по всем пропускает с `[WARN]`, названная явно — ошибка |
| Language | нет | Язык книг: `ru` (по умолчанию) или `root` (английский) |
| V8Path   | нет | Каталог `bin` платформы или путь к `1cv8.exe`. По умолчанию — `v8path` из `.v8-project.json`, затем самая свежая установленная версия |
| CacheDir | нет | Каталог индекса заголовков (по умолчанию `1c-syntax-help` во временном каталоге) |
| Limit    | нет | Макс. строк (по умолчанию 150) |
| Offset   | нет | Пропустить N строк (пагинация) |

## Книги

| Книга | Что внутри |
|-------|-----------|
| `shlang` | Встроенный язык: конструкции, директивы компиляции, инструкции препроцессора |
| `shcntx` | Глобальный контекст, типы, их методы, свойства и события — с синтаксисом, параметрами и доступностью |
| `shquery` | Язык запросов |
| `shclang` | Понятия встроенного языка: виды модулей, контекст выполнения, коллекции, временные таблицы |
| `1cv8` | Параметры запуска и ключи пакетного режима конфигуратора — страница ключа называется как ключ (`DumpConfigToFiles`) |
| `config`, `devtool`, `frntend` | Конфигуратор: поставка, хранилище конфигурации, сравнение, параметры базы |
| `debug` | Отладчик |
| `mngdsgn` | Редактор управляемых форм |
| `dcsui` | Система компоновки данных |

Остальные книги описывают диалоги интерфейса. Поиск без `-Book` идёт по всем.

## Как читать вывод

| В выводе | Что значит |
|----------|------------|
| `[8.3.27.1989] Found: N` | Версия платформы, по справке которой ответ, и число найденных страниц |
| `shcntx:objects/.../Add772.html \| Массив.Добавить (Array.Add)` | Страница: слева — значение для `-Page`, справа — заголовок |
| `[INFO] Nothing found` | Страниц нет. Попробуй часть слова, английское имя или `-InText` |
| `[WARN] Skipped unreadable help book` | Файл книги не читается как контейнер 1С; поиск по остальным книгам продолжен |

Сначала идут точные совпадения заголовка, затем заголовки, начинающиеся с запроса, затем остальные. Заголовки метода и свойства имеют вид `Тип.Член (Type.Member)`, поэтому `Массив Добавить` и `Array.Add` найдут одну и ту же страницу.

Первый поиск по книге строит индекс заголовков: на `shcntx` это около 15 секунд на PowerShell и пара секунд на Python, остальные книги вместе — ещё около секунды. Дальше индекс берётся из кэша, пока файл книги не изменится.

## Примеры

```powershell
# Метод глобального контекста
powershell.exe -NoProfile -File "${CLAUDE_SKILL_DIR}/scripts/syntax-help.ps1" -Search "СтрШаблон"

# Метод типа
powershell.exe -NoProfile -File "${CLAUDE_SKILL_DIR}/scripts/syntax-help.ps1" -Search "Массив Добавить"

# Где упоминается директива
powershell.exe -NoProfile -File "${CLAUDE_SKILL_DIR}/scripts/syntax-help.ps1" -Search "НаКлиентеНаСервере" -InText -Book shlang

# Ключи пакетного режима для хранилища
powershell.exe -NoProfile -File "${CLAUDE_SKILL_DIR}/scripts/syntax-help.ps1" -Search "ConfigurationRepository" -Book 1cv8

# Страница целиком
powershell.exe -NoProfile -File "${CLAUDE_SKILL_DIR}/scripts/syntax-help.ps1" -Page "shlang:Pragma"
```
