# /cfe-diff — Анализ расширения

Два режима: обзор изменений расширения (`overview`) и проверка их переноса в основную конфигурацию (`transfer`).

## Параметры

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `ExtensionPath` | Расширение; несколько — через запятую; каталог, в подкаталогах которого лежат расширения (обязат.) | — |
| `ConfigPath` | Основная конфигурация. Обязателен для `transfer` | — |
| `Mode` | `overview` / `transfer` | `overview` |
| `Name` | Детали только по этим объектам: `Тип.Имя`, через запятую | — |
| `Limit` / `Offset` | Пагинация тела отчёта | `150` / `0` |
| `OutFile` | Записать отчёт в файл | — |

## Команда

```powershell
powershell.exe -NoProfile -File "${CLAUDE_SKILL_DIR}/scripts/cfe-diff.ps1" -ExtensionPath src\cfe\extname
```

## Объём вывода

Итог всегда в конце отчёта. Если детали всего отчёта небольшие — они выводятся сразу. Иначе выводится только по строке на объект и строка-ориентир `Details omitted … Use -Name …`: детали по нужным объектам запроси через `-Name` (несколько — через запятую, за один вызов).

## overview — что изменено в расширении

По строке на объект: `[BORROWED]` — заимствованный, `[OWN]` — собственный. Под заимствованным:
- перехватчики модулей: `&Перед`, `&После`, `&Вместо`, `&ИзменениеИКонтроль` со строкой и файлом;
- собственные и заимствованные подобъекты;
- формы: `(borrowed, unchanged)` или разница с исходной формой (`BaseForm`) деревом в нотации `/form-info` — `+` добавлено, `~` изменено (`было→стало`), `>` перемещено; реквизиты, команды, события с `[callType]`.

`/form-info` показывает форму расширения целиком, с наложенными правками; что именно расширение поменяло в форме — здесь.

## transfer — перенесены ли изменения в конфигурацию

Каждая правка расширения ищется в основной конфигурации:

| Правка | Как проверяется |
|--------|-----------------|
| `&ИзменениеИКонтроль` | по каждому `#Вставка`/`#Удаление` (как `/cfe-patch-method -Check`), вывод `перенесено/всего edits` |
| `&Перед`, `&После`, `&Вместо`, события формы с `callType`, перехват команды | строки кода перехватчика ищутся в целевом методе по порядку — `(heuristic: найдено/всего lines)` |
| Собственный метод модуля | метод с тем же именем и тем же телом |
| Собственный реквизит, ТЧ, форма, команда, макет | наличие в объекте конфигурации; у реквизита — и тип |
| Собственный объект | наличие в конфигурации |
| Правки заимствованной формы | элемент, свойство, положение, реквизит, команда — в форме конфигурации |

Префикс расширения (`NamePrefix`) при сравнении не мешает: правка, перенесённая с ним или без него, находится одинаково — `(found as Имя)`. Роли не проверяются.

Статусы: `[TRANSFERRED]`, `[NOT_TRANSFERRED]`, `[PARTIAL]`, `[DIVERGED]` — нашлось, но отличается (сдвинут якорь вставки, другое тело метода, другой тип), `[MISSING_IN_CONFIG]` — нет целевого метода, модуля или объекта. Полностью перенесённый объект — одной строкой. В конце — `Remaining:` объекты с остатком.

Exit code `1`, если перенесено не всё.

Что уже перенесено, из `&ИзменениеИКонтроль` вычищает `/cfe-patch-method -Actualize`.

## Примеры

```powershell
# Что изменено в расширении
... -ExtensionPath src\cfe\extname

# Детали по двум объектам
... -ExtensionPath src\cfe\extname -Name Document.ЗаказКлиента,CommonModule.ОбщегоНазначения

# Перед релизом: всё ли перенесено из всех расширений каталога
... -ExtensionPath src\cfe -ConfigPath src\cf -Mode transfer

# Что осталось перенести по одному объекту
... -ExtensionPath src\cfe\extname -ConfigPath src\cf -Mode transfer -Name Document.ЗаказКлиента
```
