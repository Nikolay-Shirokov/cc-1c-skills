# События форм — полный перечень

Имя события — ключ в `events`. Обработчик по конвенции (`events: ["Событие"]`) — `<ИмяЭлемента><Суффикс>`, у события формы — сам суффикс. Параметры — новейшей платформы.

«С платформы» пусто — событие есть с 8.3.20. «Только» — событие есть лишь у таблицы с этим источником или у формы этих владельцев (по основному реквизиту); у прочих платформа выбрасывает его при загрузке.
