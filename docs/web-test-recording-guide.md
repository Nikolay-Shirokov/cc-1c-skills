# Запись видеоинструкций

Навык `/web-test` умеет записывать видеоинструкции по работе в 1С: автоматические действия в браузере записываются в MP4 с субтитрами, подсветкой элементов, анимированными слайдами и голосовой озвучкой. Результат — готовое обучающее видео.

```
сценарий → запись экрана → титул и слайды → субтитры → подсветка → озвучка голосом → MP4
```

Слайды умеют и отдельно от 1С: короткий ролик-презентация собирается из одних слайдов. В ролик можно взять и
страницы не из 1С: смежную систему в инструкции по интеграции или веб-продукт целиком.

## Предусловия

Все пути и настройки хранятся в `.v8-project.json` — см. [справочник формата](v8-project-guide.md).

### ffmpeg (обязательно)

Выберите один из вариантов:

1. **В проект** (рекомендуется) — скачать essentials build с https://www.gyan.dev/ffmpeg/builds/, распаковать в `tools/ffmpeg/`. Код найдёт `tools/ffmpeg/bin/ffmpeg.exe` автоматически

2. **Глобально** — скачать, распаковать в любой каталог, добавить `bin/` в системный PATH

3. **Через конфиг** — указать путь в `.v8-project.json`:
   ```json
   { "ffmpegPath": "C:\\tools\\ffmpeg\\bin\\ffmpeg.exe" }
   ```

### node-edge-tts (для озвучки)

```bash
npm install --prefix tools/tts node-edge-tts
```

Бесплатный, без API-ключа. Нужна версия **1.2.12 или новее** — старые получают от сервиса ошибку 403. Если не установлен — запись видео работает, только озвучка недоступна.

Синтезированные фразы кэшируются: повторная запись и переозвучка тем же голосом не синтезируют их заново.

### Конфигурация голоса в `.v8-project.json`

```json
{
  "ffmpegPath": "tools/ffmpeg/bin/ffmpeg.exe",
  "tts": {
    "provider": "edge",
    "voice": "ru-RU-DmitryNeural"
  }
}
```

## Быстрый старт

Минимальный сценарий — запись 3 шагов с озвучкой:

```js
// Начинаем запись
await startRecording('recordings/demo.mp4');

// Действие, затем подпись к нему
await navigateSection('Продажи');
await showCaption('Раздел «Продажи»');

await openCommand('Заказы клиентов');
await showCaption('Заказы клиентов');

await clickElement('Создать');
await showCaption('Новый заказ');

// Завершаем запись
await hideCaption();
const video = await stopRecording();
console.log(`Записано: ${video.duration.toFixed(1)}s`);

// Озвучка
const narrated = await addNarration(video.file, {
  ffmpegPath: 'tools/ffmpeg/bin/ffmpeg.exe',
  voice: 'ru-RU-DmitryNeural',
});
console.log(`Озвучено: ${narrated.file}`);
```

Результат: `recordings/demo-narrated.mp4` — видео с голосовым сопровождением.

## Сценарии использования

### Запись без озвучки

Простейший вариант — субтитры на экране, без голоса:

```
> Запиши видеоинструкцию: открой раздел Продажи, создай заказ клиента,
> заполни организацию и контрагента. Без озвучки
```

Claude запишет видео с субтитрами и подсветкой элементов.

### Запись с озвучкой

Полный pipeline — голос озвучивает каждый шаг:

```
> Запиши озвученную видеоинструкцию по созданию заказа клиента.
> Голос — Светлана
```

Claude запишет видео, затем наложит голосовую дорожку. Субтитры показываются на экране, параллельно звучит голос.

### Переозвучка другим голосом

Видео уже записано — хотите другой голос? Не нужно перезаписывать:

```
> Переозвучь recordings/demo.mp4 голосом Светланы
```

Claude вызовет `addNarration` с другим голосом. Тексты берутся из файла `.captions.json`, который сохраняется рядом с видео при записи.

### Ролик со слайдами

Титул, оглавление, вставки-презентации и финальный слайд — анимированные, по шагам под озвучку:

```
> Запиши видеоинструкцию по созданию заказа: титул, оглавление из трёх разделов,
> слайд со схемой процесса из slides/scheme.png с фокусом на каждом этапе,
> затем шаги в 1С и финальный слайд с контактами
```

Готовую картинку слайда можно показать «по частям»: камера наезжает на ту область, о которой сейчас говорит голос, остальное притемняется. Подробнее — в разделе «Слайды из презентации».

### Ролик без 1С

Короткая презентация из одних слайдов — без подключения к базе:

```
> Сделай ролик из пяти слайдов о новых возможностях: титул, утверждение с цифрой,
> сравнение «было/стало», итоги, финал. Озвучка — Светлана
```

Claude опишет слайды в модуле и соберёт видео командой `run.mjs play`. Перед записью можно посмотреть картинку каждого шага: `run.mjs preview` — это быстро и без озвучки.

Слайды и живой веб-продукт (портал, сервис) — тоже без 1С: сессия открывает сайт вместо базы
(`run.mjs start <адрес> --web`), между слайдами идут действия на сайте с подсветкой и озвучкой:

```
> Запиши ролик о портале: титул, два слайда о возможностях, затем на портале открыть раздел
> «Сценарии» и показать паспорт сценария, финал. Моё имя и почту на экране скрыть
```

Если на сайт нужно войти — окно сессии видимое, войдите вручную перед записью. Для повторных записей вход
можно сохранить в файл (`web.saveLogin`) и подставлять при запуске (`--login=`). Этот файл — ваш сеанс на
сайте: держите его вне git и никому не пересылайте; истёк — войдите вручную и сохраните снова.

### Ролик интеграции: 1С → смежная система → 1С

Одним роликом: действие в 1С, результат в другой системе (CRM, портал, сервис доставки), возврат в 1С. Другая
система открывается вкладкой в том же окне, запись переходит за страницей на экране:

```
> Запиши инструкцию: в 1С провести заказ, потом в CRM https://crm.example.ru/orders показать,
> что заказ появился, и вернуться в 1С к статусу оплаты
```

Подробнее — [web-pages.md](../.claude/skills/web-test/web-pages.md).

### Редактирование субтитров

После записи рядом с видео появляется файл `video.captions.json`:

```json
{
  "videoTimestamps": true,
  "captions": [
    { "text": "Переходим в раздел «Продажи»", "speech": "Переходим в раздел Продажи", "time": 3160 },
    { "text": "Открываем заказы клиентов", "speech": "Открываем заказы клиентов", "time": 7040, "voice": "bqbHGIIO5oETYIqhWmfk" }
  ]
}
```

Можно отредактировать `speech` (текст озвучки) или добавить `voice` (голос для конкретной реплики) и переозвучить:

```
> Отредактируй субтитры в recordings/demo.captions.json — замени "Продажи" на
> "раздел Продажи", потом переозвучь
```

Озвучка пишется так, как произносится: «один эс», «опен эй ай» — иначе голос споткнётся на «1С» и латинице;
на экране и в субтитрах остаётся обычное написание. Такие слова в озвучке движок отмечает предупреждением
ещё до записи (в `preview`).

## Приёмы

### Титул и финал

Анимированная заставка в начале и финальный слайд в конце. Строки названия поднимаются по очереди, линия прорисовывается, картинка справа медленно отъезжает:

```js
const TITLE = { layout: 'title', kicker: 'Видеоинструкция', title: 'Создание заказа клиента',
  subtitle: '1С:Бухгалтерия в примерах', image: 'slides/cover.png',
  speech: 'Создание заказа клиента. Бухгалтерия в примерах.' };
const CLOSING = { layout: 'closing', title: 'Спасибо за внимание', subtitle: 'Учебный центр',
  contacts: ['site.ru', 'info@site.ru'], speech: 'Спасибо за внимание!' };

await prepareSlides([TITLE, CLOSING]);       // до записи: проверка и синтез фраз
await startRecording('recordings/demo.mp4');  // видео начнётся сразу с титула
await showSlide(TITLE);
await hideSlide();
// ... шаги в 1С ...
await showSlide(CLOSING);
const video = await stopRecording();          // заканчиваем на финальном слайде
```

Слайд длится ровно столько, сколько звучит его фраза. `prepareSlides` синтезирует фразы заранее — иначе во время записи будет пауза на синтез. Статичный вариант без анимации — опция `{ motion: false }`; прежний `showTitleSlide` тоже работает как раньше.

### Слайды из презентации

Статичная картинка под длинный монолог воспринимается плохо: зритель не знает, куда смотреть. Слайд лучше показывать по шагам — каждая фраза раскрывает или выделяет свою часть.

**Готовая картинка слайда** — камера наезжает на область, о которой говорит голос, и ставит пронумерованные выноски:

```js
await showSlide({
  layout: 'image', src: 'slides/scheme.png',
  steps: [
    { speech: 'Заказ проходит три этапа:' },
    { region: [120, 80, 420, 260], speech: 'оформление,' },          // область в пикселях картинки
    { callout: { at: [760, 300], label: 'Согласование' }, speech: 'согласование и отгрузку.' },
  ],
});
```

**Слайд из шаблона** — содержимое описывается данными, оформление и анимация готовы: `agenda` (оглавление), `statement` (одна мысль, крупно), `cards` (карточки), `columns` (колонки), `comparison` (было/стало), `process` (этапы), `radial` (центр и участники вокруг), `flow` (источники → обработка → результат), `summary` (итоги). У карточки, этапа или ячейки может быть статус: подтверждено, под вопросом, не используется, необязательно — цветная полоса, значок, зачёркивание; что он значит, говорит голос. Полный перечень полей, пределов и правил — в [slides.md](../.claude/skills/web-test/slides.md).

**Своя страница** — если нужной раскладки нет: Claude рисует слайд сам (разметка, стили, шаги), а для 3D-сцены, анимации Lottie или готового видеоклипа подключает к слайду скрипт и библиотеки проекта — [slide-scripts.md](../.claude/skills/web-test/slide-scripts.md).

Цвета слайдов — тёмно-синий с янтарным акцентом на светлом фоне. Фирменный стиль проекта задаётся в
`.v8-project.json` → `"slides": { "theme": { ... } }`: цвета (в том числе тёмный фон — карточки и текст
подстроятся сами), шрифты из файлов проекта, фон всех слайдов и рамка — логотип, номер слайда, колонтитул на
каждом слайде:

```json
"slides": { "theme": { "primary": "#14213d", "accent": "#3fb68b",
  "frame": { "logo": "docs/video/logo.png", "number": true, "footer": { "text": "Учёт заказов", "at": "left" } } } }
```

Прежний `showImage` (картинка целиком, стили `blur`/`dark`/`light`/`full`) тоже работает как раньше.

### Подсветка элементов

Полупрозрачная рамка на элементе, который сейчас используется. Два режима:

- **Авторежим** — `setHighlight(true)` перед началом действий. Каждая функция (`navigateSection`, `clickElement`, `fillFields` и т.д.) автоматически подсвечивает элемент перед действием
- **Ручная** — `highlight('Провести')` для произвольной подсветки конкретного элемента

```js
setHighlight(true);   // включить авто
// ... все действия подсвечиваются автоматически
setHighlight(false);  // выключить перед stopRecording
```

На страницах не из 1С элемент указывают локатором Playwright: `web.highlight(getPage().getByText('Заказ 000123'))`,
снять — `web.unhighlight()`.

### Скрыть личные данные

Имя пользователя, почта, адрес репозитория, служебные баннеры не должны попасть в ролик. `web.mask` прячет их
по CSS-селектору или по тексту (скрывается элемент, где этот текст стоит) — и после переходов, и после
перезагрузки страницы; работает и на 1С:

```js
await web.mask(['.user-menu', { text: 'Иванов' }, { text: '@example.ru' }]);
```

### Ритм: действие, затем подпись

Сначала действие, потом подпись к нему:

```js
await clickElement('Провести');            // действие (с подсветкой, если она включена)
await showCaption('Документ проведён');    // подпись и голос — над уже открытым результатом
```

Подпись с озвучкой держит сценарий, пока звучит фраза, и следующий шаг начинается только после неё. Поэтому при обратном порядке голос рассказывал бы о форме, которой ещё нет на экране. Паузы расставлять не нужно: действие само ждёт результата, подпись — своей фразы.

### Два голоса (подкаст / диалог)

Параметр `voice` в `showCaption` задаёт голос для конкретной реплики. `addNarration` автоматически использует его вместо глобального:

```js
const MALE   = 'bqbHGIIO5oETYIqhWmfk'; // Alexander
const FEMALE = '0ArNnoIAWKlT4WweaVMY'; // Elena Gromova

// speechRate: 85 — ElevenLabs медленнее Edge TTS, нужен запас
await startRecording('podcast.mp4', { speechRate: 85 });

await showSlide({ layout: 'image', src: 'slides/slide-01.png' });   // слайд без озвучки
await showCaption('', { speech: 'Привет! Сегодня поговорим...', voice: MALE });
await wait(0.8);
await showCaption('', { speech: 'А я буду задавать вопросы...', voice: FEMALE });
await wait(0.8);

const video = await stopRecording();
const result = await addNarration(video.file, {
  provider: 'elevenlabs',
  apiKey: 'sk_...',
  // глобальный voice не нужен — каждый caption несёт свой
});
```

Приёмы:
- `showCaption('', { speech, voice })` — пустой текст (без субтитра на экране), но speech записывается для озвучки
- `showSlide` без `steps` — слайд без озвучки, реплики идут через `showCaption`; у шага слайда тоже может быть свой `voice`
- `speechRate: 85` — для ElevenLabs увеличиваем множитель (по умолчанию 70мс/символ), чтобы фразы не наезжали друг на друга

### Разделение текста и озвучки

Параметр `speech` в `showCaption` позволяет показывать одно, а озвучивать другое:

```js
// Субтитр технический, озвучка человечная
await showCaption('Дт 60.02 — Кт 51', {
  speech: 'Дебет шестьдесят ноль два — кредит пятьдесят один'
});

// Показать субтитр, но НЕ озвучивать
await showCaption('Технические детали', { speech: false });
```

Это полезно для:
- **Бухгалтерских проводок** — на экране формула, голосом — словами
- **Технических данных** — показать, но не зачитывать
- **Информационных плашек** — немой субтитр на несколько секунд

### Фоновая музыка

Своя музыка, без лицензий: шесть настроений (`bright`, `warm`, `calm`, `focus`, `uplift`, `uplift-soft`) генерируются при сведении; можно подложить и свой файл.

```
> Добавь в ролик фоновую музыку bright
> На слайде с 3D-сценой пусть играет музыка, а пока 1С формирует отчёт — focus
```

На весь ролик музыка звучит в паузах и уходит под речью; у слайда — пока он на экране; блоком — на долгих действиях без озвучки. Стыки движок сглаживает сам. Музыка хороша на титуле, витрине и паузах, а под диалогом и плотным объяснением отвлекает — одного настроения на ролик достаточно.

## Доступные голоса и провайдеры

### Какой провайдер выбрать?

| Провайдер | Тембр | Произношение русского | Цена |
|-----------|-------|----------------------|------|
| **Edge TTS** | Синтетичнее | Корректные ударения, правильная артикуляция | Бесплатно |
| **ElevenLabs** | Живее, естественнее | Возможны ошибки в ударениях и артикуляции (напр. «докумЭнт», «крЕдит» вместо «кредИт») | Платно (starter+) |
| **OpenAI** | Зависит от голоса | Заметный английский акцент; `instructions` (если модель поддерживает) его смягчают, но не убирают | Платно, модели отключаются 06.01.2027 |

**Для русскоязычных видеоинструкций рекомендуется Edge TTS** — он бесплатный и даёт надёжное качество русской речи. Голоса DmitryNeural и SvetlanaNeural специально обучены для русского языка: правильно расставляют ударения, корректно артикулируют и делают паузы в нужных местах.

**ElevenLabs** даёт более живой, «человечный» тембр — голос звучит менее синтетически. Однако мультиязычная модель иногда ошибается в произношении русских слов (особенно профессиональная терминология). Если выбираете ElevenLabs для русского контента — берите **professional-голоса** с образовательным или деловым профилем (например, Olga Orlova, Artem), они дают лучший результат, чем англоязычные premade-голоса через мультиязычную модель. Управлять ударениями через API нельзя — фонемные теги (SSML) поддерживаются только для английских моделей.

### Edge TTS (бесплатный) — рекомендуется для русского

| Голос | Описание |
|-------|----------|
| `ru-RU-DmitryNeural` | Мужской, русский — спокойный, деловой |
| `ru-RU-SvetlanaNeural` | Женский, русский — чёткий, уверенный |

Полный список: `en-US-AriaNeural`, `en-US-GuyNeural`, `de-DE-ConradNeural` и другие. Edge TTS поддерживает десятки языков.

Конфигурация не нужна — Edge TTS используется по умолчанию. Для смены голоса:

```json
{
  "tts": {
    "voice": "ru-RU-SvetlanaNeural"
  }
}
```

### ElevenLabs (платный) — живой тембр

Модель `eleven_multilingual_v2` поддерживает русский. Тембр заметно живее, чем у Edge TTS, но возможны артикуляционные ошибки на русской терминологии.

Для русского контента выбирайте **professional-голоса** с образовательным/деловым профилем из Voice Library:

| Голос | ID | Профиль |
|-------|----|---------|
| Olga Orlova | `d60rsXo2p0OwikDR5bS7` | Clear and Engaging |
| Artem | `WTn2eCRCpoFAC50VD351` | Friendly & Professional |
| Denis | `0BcDz9UPwL3MpsnTeUlO` | Pleasant, Engaging and Friendly |
| Alexander | `bqbHGIIO5oETYIqhWmfk` | Pleasant, Warm and Natural |
| Elena Gromova | `0ArNnoIAWKlT4WweaVMY` | Podcasts & Conversation |
| Victor | `9fjVd0EYNNXHllJquVdT` | Moscow accent |

```json
{
  "tts": {
    "provider": "elevenlabs",
    "apiKey": "sk_...",
    "voice": "d60rsXo2p0OwikDR5bS7"
  }
}
```

`voice` — ID голоса (не имя). Professional-голоса добавляются в аккаунт через Voice Library в личном кабинете. Требуется платный тариф (starter и выше).

Особенности: лимит на параллельные запросы (2–3 одновременно), система автоматически ограничивает размер пакета.

### OpenAI-compatible (платный)

> OpenAI объявил модели `tts-1`, `tts-1-hd` и `gpt-4o-mini-tts` устаревшими: они отключаются **6 января 2027**, а модель-преемник через этот API недоступна. После этой даты провайдер `openai` работает только с OpenAI-совместимыми сервисами через `apiUrl`.

Для русского берите модель, которая поддерживает поле `instructions` — свободное описание манеры речи (например, `gpt-4o-mini-tts`). Без инструкции русский текст звучит с заметным английским акцентом; инструкция вида «носитель языка, без акцента» его смягчает, но полностью не убирает — для русского Edge TTS звучит естественнее. Отдельные запросы к OpenAI отвечают долго (30–60 с): такой запрос обрывается через 30 с и повторяется автоматически.

```json
{
  "tts": {
    "provider": "openai",
    "apiKey": "sk-...",
    "model": "gpt-4o-mini-tts",
    "voice": "cedar",
    "instructions": "Ты носитель русского языка. Говори по-русски без иностранного акцента, спокойно и отчётливо, как диктор обучающего видео."
  }
}
```

Голоса: `alloy`, `ash`, `coral`, `echo`, `fable`, `onyx`, `nova`, `sage`, `shimmer`; у `gpt-4o-mini-tts` есть ещё `ballad`, `verse`, `marin` и `cedar`. Для лучшего качества OpenAI рекомендует `marin` или `cedar`. Без поля `model` используется `tts-1` — без инструкций и без этих четырёх голосов.

Поле `apiUrl` позволяет подключить любой OpenAI-совместимый сервис (например, локальный TTS-прокси).

## Полный пример

Типовая структура озвученного сценария:

```js
const TTS = { voice: 'ru-RU-SvetlanaNeural' };
const TITLE = { layout: 'title', title: 'Заголовок', subtitle: 'Подзаголовок', speech: 'Заголовок. Подзаголовок.' };
const SCHEME = { layout: 'image', src: 'slides/overview.png', steps: [
  { speech: 'Общая схема процесса:' },
  { region: [100, 120, 500, 300], speech: 'сначала — оформление заказа.' },
] };
const CLOSING = { layout: 'closing', title: 'Спасибо за внимание', speech: 'Спасибо за внимание!' };

await prepareSlides([TITLE, SCHEME, CLOSING], TTS);   // проверка и синтез фраз до записи
await startRecording('output.mp4');

await showSlide(TITLE, TTS);
await showSlide(SCHEME, TTS);   // слайд из презентации (опционально)
await hideSlide();

setHighlight(true);

// ... шаги: действие, затем showCaption ...

await hideCaption();
setHighlight(false);
await showSlide(CLOSING, TTS);
const video = await stopRecording();

const narrated = await addNarration(video.file, {
  ffmpegPath: 'tools/ffmpeg/bin/ffmpeg.exe',
  ...TTS,
});
```

## Типичные проблемы

| Проблема | Решение |
|----------|---------|
| `ffmpeg not found` | Установите ffmpeg (см. Предусловия) |
| Файл записи 0 байт | Проверьте права на запись в выходной каталог |
| Видео дёргается | Добавьте `wait()` между шагами |
| `Already recording` | Вызовите `stopRecording()` перед новой записью |
| `No captions available` | Используйте `showCaption()` во время записи |
| TTS timeout | Проверьте интернет-соединение (Edge TTS требует сеть) |
| Озвучка обрезается | Увеличьте паузы `wait()` между субтитрами |
| Фразы наезжают друг на друга | Увеличьте `speechRate` в `startRecording` (85 для ElevenLabs) |
| TTS: ошибка 403 | Обновите `node-edge-tts` до 1.2.12 или новее |
| Пауза в видео перед слайдом | Вызовите `prepareSlides([...])` до `startRecording` — фразы синтезируются заранее |
| `showSlide(...) WARN` в выводе | Текст за краем, мелкий шрифт или много текста — сократите пункты или разделите слайд; картинка каждого шага — `run.mjs preview` |
| `showSlide(radial): 3–6 cards supported` | Превышен предел шаблона — разделите слайд или возьмите другой шаблон (совет — в тексте ошибки) |
| На сайте каждое действие ждёт ~30 с | В сценарии ожидание сети (`networkidle`) — уберите: действия Playwright сами ждут элемент, а многие сайты никогда не «затихают» |
| Сайт снова просит войти | Сохранённый вход истёк — войдите вручную в окне сессии и `web.saveLogin` заново |
